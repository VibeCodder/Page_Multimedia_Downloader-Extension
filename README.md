# Page Multimedia Downloader
As title suggest it's a browser extension created with Claude that allows to download both images and videos.<br>
For longer videos, you can move extension to a new browser tab by clicking `Open in tab` <br>
to prevent stopping downloading caused by accidentally closed popup.
